# Send a Grapevine File

Sending your character's Grapevine exchange file to a chronicle, so a Storyteller there can
review it and let you in - as a new player, or as a visitor for one game.

## Who can use this

Anyone signed in, whether or not you already belong to the chronicle you're sending to.

## How to get there

My Chronicle → **Send a Grapevine file** (beside **+ New Character** on the Characters tab), or
**Send a Grapevine file to a chronicle** if you don't belong to a chronicle yet. A Storyteller
may also hand you a direct link to this page with their chronicle already picked.

## The screen

- **Chronicle** - every chronicle on the site, grouped into **Your chronicles** and **Other
  chronicles**. A link from a Storyteller starts you on their chronicle already.
- **Grapevine file** - pick a `.gex` file. Nothing is sent yet - this just reads it.
- Once read: the character it holds (or, for a file with several, a list to pick yours from),
  each with a reason if it can't be sent to this chronicle.
- **Are you joining or visiting?** - **Joining** the chronicle for good, or **Visiting for a
  game** (with an optional **Home chronicle** to tell the Storyteller where you're from).
- **Send**.
- **Your sent files** - every chronicle you've sent a file to, its status, and **Withdraw** on
  one still waiting.

## Common tasks

### Send your character to a chronicle

1. Open **Send a Grapevine file**.
2. Pick the chronicle.
3. Pick your `.gex` file.
4. If the file holds more than one character, pick yours.
5. Choose **Joining** or **Visiting for a game**.
6. Click **Send**.

### Pick yours from a file with several characters

1. After picking the file, find yours under **Which one is yours?**
2. Select it. A character you can't send here shows why, and can't be selected.

### Withdraw a file you sent by mistake

1. Find it under **Your sent files**, still **Waiting for review**.
2. Click **Withdraw**.

## Things to know

- **One waiting file per chronicle.** You can't send a second one to the same chronicle - and a
  chronicle where you've asked to join by starting a character by hand works the same way; only
  one request of either kind waits at a time.
- **Only your character is sent.** The rest of the file - other players, items, locations - never
  leaves your computer.
- **Nothing is added until a Storyteller accepts.** Sending starts a review, not a membership.
- **Accepting makes you a player there.** Once accepted, the character is yours in that
  chronicle - active immediately, since a Storyteller's acceptance is itself the approval.
- **A verification code travels with the file, if it has one.** A `.gex` exported from Beyond
  Elysium with its verification code included lets the Storyteller see whether it still matches
  what was exported.
- **An unanswered file expires after 60 days.**

## Troubleshooting

- **"You already have a sheet waiting for [chronicle]."** Withdraw it first, or wait for an
  answer.
- **"This file doesn't hold a character."** The file parsed, but has nothing in it to send.
- **"This isn't a Grapevine exchange file." / "This is a whole game file."** Export just your
  character as a `.gex` exchange file from Grapevine, not a whole chronicle file.
- **"This file is larger than 5 MB."** Export just your character, not everything.
- **A character shows a reason instead of a Send option.** That creature type, or one of its
  values, isn't allowed in this chronicle right now.
- **I don't see this page at all.** It needs a signed-in account - anyone has one.
