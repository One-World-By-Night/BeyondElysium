# Game Dashboard

Chronicle-wide numbers for a Storyteller: character and change counts, active plots, roster
health, and recent activity across every character - not just your own.

## Who can use this

Storytellers (HST and AST). The Storyteller Toolkit's Dashboard tab only appears at all for
them - a Narrator or the chronicle's Harpy works from their own tabs there (Plots & Rumors or
Boon Ledger) instead, and a plain player doesn't see the Storyteller Toolkit at all. Opening
My Chronicle's own Dashboard tab shows this same chronicle-wide view for a Storyteller;
anyone else there sees their own [Dashboard](player-dashboard.md) instead.

## How to get there

- Storyteller Toolkit → Dashboard tab (the first tab, where the page opens by default).
- Also: My Chronicle → Dashboard, for a Storyteller looking at their own player-facing page.

## The screen

Five cards in a row:

- **Characters** - the chronicle's total character count, broken down by creature type
  underneath.
- **Pending Changes** - how many changes across the chronicle are currently awaiting review.
- **Active Plots** - how many plots currently carry `active` status.
- **Characters Needing Attention** - how many active characters are currently **Flagged** on
  the spotlight check - no staff post in a while, or none ever. See
  [Game Nights](game-nights.md)'s own Spotlight section for the full list.
- **By Status** - the same total character count, broken down by status underneath.
- **Players Without an Active Character** - a count; click it to expand the list of who they
  are, or collapse it again.

Below the cards, **Recent Activity** lists the ten most recently submitted changes across the
whole chronicle, each naming the character, a plain description of what changed, and its
current status. It reads "Nothing yet." when there's none.

## Common tasks

### Check the chronicle's overall numbers

1. Open Storyteller Toolkit and pick a chronicle, if you haven't already.
2. Read the cards across the top.

### See which players have no active character

1. Click the **Players Without an Active Character** card.
2. Read the names, or "Everyone has an active character." if the list is empty.
3. Click the card again to collapse it.

### Check recent activity

1. Read down **Recent Activity**.

## Things to know

- **The numbers refresh automatically** the moment a change is approved or rejected
  elsewhere in the chronicle; short of that, they can be up to a minute stale.
- **Recent Activity isn't only reviewed changes.** A change still pending can show here too,
  alongside ones already approved or rejected.
- **"Players Without an Active Character" counts two situations as one.** A player with no
  character at all counts the same way as a player whose only character has gone inactive.
- **This tab reads the whole chronicle.** There's no way to scope it to a single player or
  character from here - for one player's own view, see [Dashboard](player-dashboard.md); for
  one character's own history, see [Change History](sheet-history.md).

## Troubleshooting

- **"Failed to load the dashboard."** Refresh and try again.
- **I don't see this tab.** You're not an HST or AST in the chronicle currently selected -
  check the **Chronicle** dropdown, or ask an HST/AST to check your role.
- **A number looks out of date.** Switch to another tab and back, or reload the page - either
  one forces a refresh.
