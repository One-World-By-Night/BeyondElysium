# Joining a Chronicle

Ask a chronicle's Storytellers to let you in: a short message, or starting a character, or sending a Grapevine file - any one of the three is its own way to ask.

## Who can use this

Anyone signed in who isn't already a member of the chronicle. A chronicle can turn join requests off; an applicant can't reach one that has.

## How to get there

Open [My Chronicle](my-chronicle.md) and use **Chronicles you can ask to join**, or follow a join link a Storyteller shared with you - either lands on the Join panel for that chronicle.

## The screen

- **Chronicles you can ask to join** - every chronicle on the site taking join requests that you aren't already a member of, each with an **Ask to join** button.
- The **Join panel**, once you've picked a chronicle:
  - A message box and **Send request** - a short note to the chronicle's Storytellers, nothing more. Up to 1,000 characters.
  - **Start a character** - opens the character editor for that chronicle right there. Building and sending a character is itself your way of asking; no message is required alongside it.
  - **Send a Grapevine file** - opens [Send a Grapevine File](send-grapevine-file.md) for that chronicle, with "joining" already picked.
  - Once you've asked with a message, the panel shows it back to you with **Withdraw** instead of the three choices above. Starting a character or sending a file doesn't show here - that waiting state is on the Characters tab and the file's own status instead.

## Common tasks

### Ask with a message

1. Open the Join panel for the chronicle.
2. Write a short message - who you are, what you'd like to play, anything they should know.
3. Click **Send request**.
4. A Storyteller reviews it. You're emailed when they approve or refuse it.

### Ask by starting a character

1. Open the Join panel for the chronicle.
2. Click **Start a character**.
3. Build it the same way you would any new character - see [Character Editor](character-editor.md).
4. Once you create it, it waits for a Storyteller to approve it. You become a player here, and can open its sheet, once they do.

### Ask by sending a Grapevine file

1. Open the Join panel for the chronicle and click **Send a Grapevine file**, or go straight to [Send a Grapevine File](send-grapevine-file.md) and pick the chronicle there.
2. Make sure **Joining** is picked, not **Visiting**.
3. Send it. A Storyteller reviews it from Import.

### Withdraw a message-only request

1. Open the Join panel for the chronicle - the waiting view shows automatically.
2. Click **Withdraw**.

## Things to know

- **A character or a file you started for the request is yours to lose.** Refusing the request deletes a character you started for it; a Grapevine file is reviewed on its own terms from Import and isn't deleted by a refusal.
- **One waiting request per chronicle.** Asking again while one is waiting is refused - withdraw it first, or wait for an answer.
- **Three asks a day per chronicle.** After asking three times in a day, a fourth is refused until the next day, even if you withdrew the others.
- **Starting a character or sending a file doesn't need a message first.** Each is its own complete way to ask; you don't have to send a message and then also start a character.
- **A network account becomes a subscriber on this site the moment you ask**, even before a Storyteller answers - that's what lets the character editor and the build tally work for you as an applicant.
- **Approval is the moment you become a player.** Nothing is granted while a request, a character, or a file is still waiting.

## Troubleshooting

- **The chronicle I want isn't listed.** It may have turned join requests off, or you may already be a member of it.
- **"This chronicle is not taking join requests right now."** Its Storytellers turned the switch off. Ask them directly.
- **"You already have a request waiting for this chronicle."** Open the Join panel - the waiting view with **Withdraw** is there instead of the ask form.
- **"You are already a member of this chronicle."** Check [My Chronicle](my-chronicle.md)'s own chronicle dropdown; it's already there.
