# Who's Who

A directory of the chronicle's NPCs, showing only what a Storyteller has chosen to make public about each one: a display name, a description, and a portrait. Never the NPC's sheet, who's assigned to it, or anything Storyteller-only.

## Who can use this

Any member of the chronicle. A player only sees the NPCs whose profile is set to reach them; a Storyteller (HST, AST, or Narrator) sees every NPC in the chronicle regardless of that setting.

## How to get there

My Chronicle → Who's Who tab.

## The screen

One card per visible NPC:

- **Portrait** - the NPC's Who's Who image, if one is set.
- **Name** - the NPC's Who's Who display name if set, otherwise its real name.
- **Description** - the write-up a Storyteller wrote for players to read. A `[ST]...[/ST]` marked passage is stripped out here the same as everywhere else.
- **Titles** / **Factions** - always empty for now. Nothing in this release assigns an NPC a title or a faction membership yet; the fields are here because the directory is meant to show them once something does.

Nothing here is editable - a Storyteller sets it up from the NPC's own [Character Editor](character-editor.md), in the Who's Who Profile section shown only there.

## Things to know

- **An NPC with no profile set up doesn't appear here at all**, for anyone but a Storyteller. Giving an NPC a public presence is an opt-in step a Storyteller takes on purpose, not something that happens by creating the NPC.
- **This is not the character list.** Player characters never appear here, and an NPC's real sheet, assignment, and Storyteller-only notes are never part of this projection.

## Troubleshooting

- **"Failed to load Who's Who."** Refresh and try again.
- **An NPC I expected to see isn't here.** Either it has no public profile set up yet, or its profile's audience doesn't currently reach you - ask a Storyteller.
