# Documentação

Uma visão somente leitura dos guias que vêm no próprio Beyond Elysium - do Narrador, do administrador, do jogador e a referência da API REST - como quatro abas dentro do wp-admin.

## Quem pode usar

Qualquer pessoa que alcança o wp-admin. Como o [Painel do Administrador](admin-dashboard.md), esta página só confere se você pode ver personagens, afinal - uma capacidade que todo papel básico do WordPress tem por padrão, até um Assinante comum - então não é protegida por nenhum papel de Narrador ou administrador. Na prática, quem a abre são sobretudo Narradores e administradores do site; um jogador comum raramente tem motivo para estar no wp-admin.

## Como chegar lá

Barra lateral do wp-admin → Beyond Elysium → Documentação.

## A tela

- Quatro abas: **Guia do Narrador**, **Guia do Administrador**, **Guia do Jogador**, **Referência da API REST**.
- Clicar numa aba carrega o conteúdo desse guia e o renderiza abaixo, na primeira vez que você a abre - voltar a uma aba que você já abriu não recarrega.
- Um link dentro de um guia que aponta para outro dos quatro guias troca de aba aqui em vez de sair da página; qualquer outro link se comporta como um link comum.

## Tarefas comuns

### Ler um guia

1. Abra Beyond Elysium → Documentação.
2. Clique em **Guia do Narrador**, **Guia do Administrador**, **Guia do Jogador** ou **Referência da API REST**.

### Seguir uma referência cruzada entre guias

1. Clique num link dentro do guia que você está lendo.
2. Se ele aponta para um dos outros três guias, esta página troca para essa aba no lugar.

## O que saber

- **Isto espelha os arquivos que vêm no próprio plugin - não é um editor ao vivo.** Nada aqui pode ser mudado pela tela; o arquivo-fonte do próprio guia precisa mudar, e o plugin precisa lançar uma versão nova, para qualquer coisa mostrada aqui ser diferente.
- **Esta é uma das poucas páginas de administração que um jogador comum pode abrir tecnicamente.** Mostra os mesmos quatro guias a todos, seja qual for o papel - nada aqui é restrito a uma crônica nem escondido.
- Toda página de administração do Beyond Elysium, esta inclusive, traz uma pequena linha de homenagem no fim: "In Memory of Arielle 'XP Day' M."

## Solução de problemas

- **Uma aba mostra um erro em vez do guia.** O arquivo que vem no plugin para esse guia não pôde ser lido - recarregue a página; se continuar acontecendo, avise o administrador do seu site.
- **Um link dentro de um guia não trocou de aba.** Só um link para um destes mesmos quatro guias faz isso - um link para uma seção específica em outro lugar, ou para qualquer coisa fora destes quatro documentos, abre ou navega normalmente.
